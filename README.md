# voice-timer

## Цель
Создать веб-приложение 'Голосовой таймер' с поддержкой PWA, голосового счёта и точным воспроизведением звука.

## Структура
- `src/index.html` — интерфейс и логика таймера (минуты 1–60, Старт / Стоп / Сброс, выбор голоса).
  Озвучка — только заранее записанные файлы из `src/audio/` через Web Audio API (синтез речи браузера не используется).
  Все фразы планируются на аудиочасах в момент старта и каждые 100 мс сверяются с `performance.now()`
  (поправка, если расписание уехало больше чем на 20 мс). Экран и звук идут по одним часам: цифра меняется
  (каждый кадр, requestAnimationFrame) в тот же момент, когда фраза доходит до динамика — время старта
  фраз сдвинуто на задержку вывода `AudioContext.baseLatency + outputLatency`. Wake Lock держит экран включённым;
  вибрация — Vibration API (Android) или тактильный отклик iOS 18+ на нажатие кнопок.
  Наличие аудио проверяется при загрузке голоса: если нет `phrases.json`, файлов фраз (404, пустой файл,
  SPA-заглушка `text/html`) или они не декодируются — над кнопками появляется сообщение с причиной
  («аудиофайлы отсутствуют» + команда генерации / «нет сети, голос не сохранён» / список недостающих фраз
  для выбранной длительности) и кнопкой «Повторить». Таймер при этом работает без звука.
- `src/audio/voices.json` — список готовых голосов (создаёт `make_audio.py`)
- `src/manifest.json` — манифест PWA
- `src/sw.js` — service worker (офлайн-кэш оболочки и аудио). Оболочка — из кэша с фоновым обновлением,
  навигация с любыми параметрами офлайн отдаёт `index.html`. После загрузки голоса страница просит SW
  докачать все его файлы в кэш (на первом визите страница ещё не под контролем SW), затем показывает
  «доступен офлайн» и запрашивает `navigator.storage.persist()`. При возврате сети недокачанное грузится заново.
- `src/icons/` — иконки (SVG + PNG 192/512, maskable, apple-touch-icon)
- `tools/make_icons.py` — генерация PNG-иконок: `./sandbox python tools/make_icons.py`
- `tools/make_audio.py` — озвучка всех фраз через macOS `say` → обрезка тишины ffmpeg → `src/audio/<голос>/*.m4a`
  (+ `phrases.json`). Запускается **на хосте macOS** (в песочнице нет `say`), нужен `brew install ffmpeg`:
  `python3 tools/make_audio.py --voice Milena` · `--list-voices` · `--dry-run` · `--force`

## Запуск локально
PWA и service worker работают только по HTTPS или на `localhost`:

    cd src && python3 -m http.server 8000

Откройте http://localhost:8000. Для установки на телефон нужен HTTPS-хостинг
(iOS: Safari → «Поделиться» → «На экран Домой»; Android: Chrome → «Установить приложение»).
